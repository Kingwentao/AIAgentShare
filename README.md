# AIAgentShare

用于创造和存储 Agent 相关内容的统一仓库。

## 目录结构

| 目录 | 用途 |
|---|---|
| `agents/` | Agent 源码与配置（系统提示词、工具配置、入口脚本） |
| `reports/` | 研究报告、竞品分析、技术方案等文档产物 |
| `prompts/` | 可复用的 Prompt 与提示词模板 |
| `media/` | 图片、视频、音频等多媒体内容 |
| `sources/` | 用户提供的源文件（书籍、文档、数据等原始素材，只读） |
| `beautiful-html-templates/` | HTML 模板库（独立子项目） |

## 规范

AI 工具与智能体在本项目内创作内容时，请遵循 [AGENTS.md](./AGENTS.md)。
